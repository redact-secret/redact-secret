# Issue #523: CI-provider credential ranking and Travis CI contract

[Audit archive](../../README.md) ·
[Issue #523](https://github.com/redact-secret/redact-secret/issues/523) ·
[Spec: detector families](../../../specs/detector-families.md)

Written 2026-09-24. This record ranks the CI-provider candidates, freezes the
Travis CI API token contract, and records what the new
`travisci-api-token` detector costs. It holds synthetic values only.

## Verdict

The maintainer chose Travis CI on 2026-09-24. It is implemented as
`travisci-api-token` (`travisci_api_token`, provider pack, confidence-gated).
The tier is T2, tool-corroborated. CircleCI and Buildkite are the next
candidates and each needs its own contract issue. GitHub Actions has no token
grammar and is not a candidate.

## Ranking

Criteria, from the issue: usage probability and lexical evidence. A provider
whose token is opaque and context-dependent ranks below one with a documented
prefix, regardless of popularity. The lexical evidence comes from the pinned
inventory (`redact-secret-benchmarks` `benchmarks/detector-inventory.json`,
gitleaks `83d9cd68`, trufflehog `363923b9`), first recorded on this issue
when it was deferred from beta.6.

| 2 | CircleCI | none | `circleci/v1`, `circleci/v2` | 1 | not checked | follow-up candidate |

The two criteria conflict. Travis CI has the strongest corroboration and the
lowest current usage of the three. The maintainer resolved the conflict in
favour of lexical evidence. No candidate has a provider-documented prefix, so
none can reach T1 from this issue.

## Travis CI contract

- **Provider documentation.** Checked 2026-09-24:
  `developer.travis-ci.com/authentication` and
  `docs.travis-ci.com/user/triggering-builds`. Both show the token only as
  `xxxxxxxxxxxx` inside an `Authorization: token` header, generated by
  `travis token`. Neither page states a length or an alphabet.
- **gitleaks 8.30.1 `travisci-access-token`.** A case-insensitive `travis`
  keyword before an assignment operator, then `[a-z0-9]{22}` under `(?i)`.
- **trufflehog 3.97.4 `travisci`.** A `travis` keyword prefix, then
  `\b[a-zA-Z0-9_]{22}\b`.
- **Frozen grammar.** A 22-byte `[A-Za-z0-9]` run, the two tools'
  intersection, on a line that contains `travis` case-insensitively. The run
  must mix letters and digits and must not be one repeated character. A value
  under a key ending in an identifier segment (`_slug`, `_id`, `_number`,
  `_url`, ...) is skipped.
- **Confidence.** High for a value assigned to a Travis-named key
  (`TRAVIS_TOKEN=`) or to a high-signal key on a Travis line. Medium (warn)
  for any other same-line keyword, per
  [`decision-redact-provider-named-credential-assignments`](../../../decisions/2026-09-24-redact-provider-named-credential-assignments.md).

## False-positive and false-negative trade-off

- **False negatives.** A token without `travis` on its own line is missed:
  an `Authorization: token` header whose Travis host is on another line, or
  bare `travis token` output. So is a token with no digit (about 2 % of
  uniformly random 22-byte tokens) or no letter. Any Travis token that is not
  22 bytes is missed too.
- **False positives.** A 22-byte mixed alphanumeric value under a
  non-identifier key on a line that mentions Travis. Travis build, job and
  repository ids are numeric and commit SHAs are 40 hex bytes, so the
  identifiers found on Travis lines do not fit the shape.
- **Generic overlap.** `travis`/`travisci` joined `generic-token`'s
  dedicated-provider name segments, so a near miss under `TRAVIS_TOKEN=`
  stays silent instead of being claimed by `generic-token`.

## Conformance

`conformance/fixtures/synchronous-corpus.json` gains 19
`travisci-api-token-*` fixtures:

- 8 positives: dotenv, JSON, YAML, shell export, CLI flag, `curl` header, log
  prose, and CRLF with a Unicode prefix;
- 6 negatives: no keyword, keyword on another line, env reference, filler, an
  identifier key, and letters only;
- 3 malformed boundaries: 21 bytes, 23 bytes, and a run embedded in an
  identifier;
- 1 overlap with `generic-token`;
- 1 dense adversarial line of 100 tokens.

Every fixture value is locally constructed and synthetic.
